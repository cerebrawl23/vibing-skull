## Tool Categories Explained

### AI Code Assistants
Tools that directly help you write code - from autocomplete to autonomous agents that can make multi-file changes.

### AI Design/UI
Tools that bridge the gap between design and code - generate UIs from text, convert screenshots to code, or build entire apps from prompts.

### Prompting & Context
Resources and tools to help you communicate better with AI - prompt templates, context management, and best practices.

### Deployment & Backend
Modern infrastructure for shipping your apps - databases, hosting, edge functions, and backend-as-a-service platforms.
